# Королевские шахматы 100

Вариация шахмат на доске 10×10 клеток.

Работает в браузере через WASM на форкнутом/доработанном движке Stockfish.

Онлайн-версия доступна на https://royalchess100.com

# Royal Chess 100

A chess variant played on a 10×10 board.

Runs in the browser via WASM on a forked/modified Stockfish engine.

The online version is available at https://royalchess100.com
